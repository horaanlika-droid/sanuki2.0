# SANUKI 2.0 — Telegram-бот + веб-приложение

Конструктор удона SANUKI: **бот и сайт связаны в единое целое** — общая база,
одинаковые статусы заказов, мгновенная синхронизация. Оформите заказ в боте — он
появится в веб-админке; смените статус на сайте — клиент получит уведомление в боте (и наоборот).

## Что внутри

| Модуль | Назначение |
|---|---|
| `app.py` | Точка входа: поднимает веб (FastAPI, порт `WEB_PORT`) и бота в одном процессе |
| `bot.py` | Telegram-бот (aiogram 3): заказы, статусы, админ-панель, кнопка веб-приложения |
| `webapp/` | Веб-приложение (SPA): конструктор удона, корзина, мои заказы, тёмная админка |
| `webapp/server.py` | API + SSE-поток живых событий |
| `core.py` | Общее ядро: одна БД (`sanuki.db`), единые статусы, шина событий бот↔веб |
| `webbridge.py` | Уведомление админов о заказах с сайта (тот же формат, что из бота) |
| `payments.py` | **Заглушка ЮMoney** — эмулирует оплату, пока не подключена реальная API |
| `menu.json` | Меню (общее для бота и веба) |

## Единые статусы заказа (одинаково в боте и на сайте)

`Новый → Принят ✅ → Готовится 🔪 → Готов 🍜 → Выдан 🎉` (+ `Отменён ❌`)

Смена статуса в любом месте (бот / сайт) обновляет второй и отправляет клиенту уведомление.

## Запуск на BotHost

Нужны только **три переменные окружения**:

```bash
BOT_TOKEN=токен_из_BotFather
ADMIN_ID=ваш_telegram_id
YOOMONEY_API=ключ_юmoney     # пока можно оставить пустым — работает заглушка
```

Опционально: `WEB_BASE_URL` — публичный https-адрес веба (для кнопки «Открыть на сайте»),
`WEB_PORT` — порт веб-приложения (по умолчанию `8000`).

### Docker

```bash
docker build -t sanuki .
docker run -d --name sanuki \
  -p 8000:8000 \
  -e BOT_TOKEN="..." -e ADMIN_ID="..." -e YOOMONEY_API="..." \
  sanuki
```

### Без Docker

```bash
pip install -r requirements.txt
python app.py
```

Веб-приложение: `http://host:8000` · Админка: `http://host:8000/#/admin` (войти по ADMIN_ID).

## Как связаны бот и веб

- **Общая БД** (`core.py`) — заказы, пользователи, история статусов.
- **Шина событий (SSE)** — сайт мгновенно узнаёт о смене статуса, сделанной в боте.
- **Заказ с сайта** → боту админу приходит сообщение «Новый заказ · С САЙТА»
  с кнопками `Принять / Готовим / Готово / Выдан / Отменить`.
- **Заказ из бота** → появляется в веб-админке и в «Моих заказах» на сайте.
- Кнопка **«SANUKI / Открыть на сайте»** в меню бота открывает веб-приложение
  (Telegram Mini App — заказы привязываются к telegram_id автоматически).

## Оплата (ЮMoney — заглушка)

`payments.py` эмулирует платёж: заказ помечается оплаченным, бейдж «тестовый платёж».
Когда будет готов ключ `YOOMONEY_API`, метод `create_payment()` заменяется на реальный
вызов API — интерфейс и остальной код менять не нужно.

## Структура проекта

```
app.py            # запуск бота + веба
bot.py            # Telegram-бот
core.py           # общее ядро (БД, статусы, события)
webbridge.py      # мост админ-уведомлений
payments.py       # заглушка ЮMoney
menu.json         # меню
webapp/
  index.html      # SPA
  server.py       # API сервера
  assets/         # графика из брендового постера SANUKI
```
